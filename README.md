# 3D Solar System Portfolio

An interactive and immersive 3D personal portfolio built with React, Three.js, and React Three Fiber. Navigate through a cinematic solar system experience to explore my skills and projects.

## Features

- **Interactive 3D Solar System:** A fully interactive environment built with `@react-three/fiber` and `@react-three/drei`.
- **Cinematic Animations:** Smooth, scroll-based navigation and camera transitions between planets.
- **Modern UI:** Built with React and animated using `framer-motion`.
- **Responsive Design:** A beautifully styled user interface using standard modern CSS.

## Tech Stack

- **Framework:** React 18 built with Vite
- **3D Graphics:** Three.js & React Three Fiber
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```
